How to type free-response answers
One number
Type the number: −5 6.5 7/2. Leave fractions as fractions instead of rounding. Writing y = in front is optional.
Ordered pairs and triples
Type the values in order, separated by commas: (5, −4) for (x, y) and (4, 0, −5) for (x, y, z). The parentheses are optional, and x = 5, y = −4 also works.
