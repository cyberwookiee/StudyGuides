Claude skill

Study Quiz Builder

Turn photos of worksheets, notes or a list of topics into a self-grading practice quiz, published as its own web page on your GitHub Pages site.

Download the skill Read the instructions GitHub setup guide

What it does

  • Reads class material for any subject and groups it into quiz sections.
  • Writes about 50 questions: multiple choice, true/false and typed answers, with graphs and diagrams where they help.
  • Targets the mistakes it spots in the student's work.
  • Checks every answer key and grader before publishing.
  • Grades instantly in the browser, shows per-section scores, saves progress on the device, and works on phones.
  • Scans each page so no names, schools, locations or other personal details are ever published.

Getting started

  1. Download the skill file and add it to Claude in your skills settings.
  2. Ask Claude for a quiz and attach photos of the material, for example: “Make a practice quiz from these biology worksheets.”
  3. The first time, Claude asks which GitHub repo to publish to and remembers it. No repo yet? Claude walks you through the one-time setup.
Quizzes are public web pages. Anyone with a link can open them, which is why the skill keeps every personal detail out.
